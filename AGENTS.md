# Skillcanon

A studio that turns a description into a portable Agent Skill, projects it for Cursor and Claude Code, and checks it.

## Agent skills

### Issue tracker

GitHub Issues in this repo, via `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default role names: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.
